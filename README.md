# REFEED
DIME project

I created this repository so we could work with the website together efficiently.
Here are some steps you'll need to complete in order to begin writing code:
1. Install Git https://git-scm.com/install/windows (or whatever other system you have, just download from this website)
2. Create a GitHub account
3. Send me your username and wait for me to add you to the project collaborators
5. Create some folder for the project and open it in your IDE (e.g. VS Code)
6. Open a terminal in your IDE and make sure you're in the right folder. After this write "git clone https://github.com/AndriiVus/REFEED"
7. Now you can create whatever files and write whatever code you want
8. When you're finished, don't forget to write "git pull" into the terminal. It's done so your changes don't overwrite someones work
9. When it's clear that there's no conflicts, write into the terminal "git commit -m "name of your commit""
10. And, finally, write "git push"
